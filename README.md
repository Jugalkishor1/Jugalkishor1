# 💫 About Me:

I'm a Full Stack Developer with 4 years of experience specializing in Ruby on Rails, Python (Django, React, and modern web technologies.

* Backend: Ruby on Rails, Python, Django, DRF, FastAPI, REST APIs, GraphQL
* Frontend: React, TypeScript, JavaScript
* Databases: PostgreSQL, SQL
* Real-time: ActionCable, WebSockets
* Payments: Stripe, Stripe Terminal, Moneris
* State Management: Zustand, TanStack Query
* Architecture: Multi-tenant SaaS applications, API integrations, scalable system design

I'm passionate about writing clean, maintainable code, solving complex problems, improving application performance, and continuously learning new technologies.
